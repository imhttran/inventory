# inventory

Shared context lives one folder up, in the parent `agentic-workspace/` folder. Read it before doing anything else.

- `../ABOUT_ME.md` — who Tom is and how he likes to work
- `../notes/writing-rules.md` — how to write here
- `.agent/about-me.md` and `.agent/writing-rules.md` — pointers to the two files above
- `README.md` — this project's own docs

Don't copy any of that content into this repo. The parent folder holds context shared by every project, and `ABOUT_ME.md` says not to duplicate it per project. The `.agent/` files here stay pointers on purpose.

When this project's own context conflicts with the parent folder's, this project wins.
